# Coffee-Ratio
[![Build Status](https://travis-ci.org/johnmahlon/Coffee-Ratio.svg?branch=master)](https://travis-ci.org/johnmahlon/Coffee-Ratio)

![app screenshot](screenshot.png)

This is an open source iOS app made to help home brewers brew their coffee by calculating the grams of water needed,
and run a timer all in the same screen. 

This is perfect for:
- Chemex
- French Press
- V60
- Drip Pot
- other slow bar methods

## Project Structure

The project follows a standard iOS app structure:
- `Ratios/` - Main application code
- `RatiosTests/` - Unit tests
- `RatiosUITests/` - UI automation tests

## Requirements

- Xcode 12.0 or later
- iOS 14.0 or later
- Swift 5.0 or later

## Installation

1. Clone the repository:
```bash
git clone https://github.com/johnmahlon/Coffee-Ratio.git
cd Coffee-Ratio
```

2. Open the project in Xcode:
```bash
open Ratios/Ratios.xcodeproj
```

3. Build and run the project using Xcode's built-in simulator or connect your iOS device.

## Usage

1. Enter the amount of coffee (in grams) you plan to use
2. The app will automatically calculate the recommended amount of water based on standard coffee ratios
3. Use the built-in timer to track your brew time
4. Enjoy your perfectly proportioned coffee!
